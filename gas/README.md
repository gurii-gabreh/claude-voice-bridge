# claude-voice-bridge トラッカーのGitHub同期リレー(GAS)

## これは何か

このGASは2つの用途で使われます。いずれも書き込み権限を持つGitHub PAT(Personal Access Token)を、ブラウザ(誰でも開発者ツールで見られる環境)には一切持たせず、このGASの「スクリプト プロパティ」にのみ保存する中継役です。

1. **トラッカー(相談・作業タスク一覧)の同期**: サイドパネルの**「☁️ GitHubへ同期」ボタンを押した時だけ**、その時点のトラッカー全体を`data/tracker.json`へ上書き保存します。
2. **ルーム内容のナレッジ化**: サイドパネルの**「🔍 ルームタスク一覧を抽出」ボタンを押した時だけ**、その1回分の抽出結果(要約せず全文)を`data/knowledge-log.json`へ1件追記します。「実際にやり取りした内容をナレッジとして残し、次の開発に活かしたい」という目的のため、音声応答(Voiceモード)や常時監視からは呼びません。1回の抽出=1件の追記なので、押すたびに全体を送り直すよりcommitが小さく済みます。

study-app(`gurii-gabreh/study-app`)にも同じ仕組みのGASがありますが、**完全に別のプロジェクト・別のPAT**です(最小権限の原則により、リポジトリごとにアクセス範囲を分離しています)。

どちらも自動ではなく、対応するボタンを押した時のみ同期します(常時監視で頻繁に検出されるデータをそのたびに自動commitすると、履歴が大量になってしまうため、あえて手動トリガーのみにしています)。

## デプロイ手順(ユーザー側の作業)

1. https://script.google.com で新規プロジェクトを作成する(study-app用とは別に、新しいプロジェクトとして作成してください)。
2. エディタの中身を全部消して、このフォルダの`code.gs`の内容をそのまま貼り付ける。
3. 「プロジェクトの設定」(⚙️)→「スクリプト プロパティ」で、以下の3つを追加する。

   | プロパティ名 | 値 |
   |---|---|
   | `GITHUB_TOKEN` | GitHubで新規発行する fine-grained Personal Access Token。**claude-voice-bridgeリポジトリのみ**に、`Contents: Read and write`権限を付与したもの(study-app用PATとは別に新規発行してください) |
   | `REPO_OWNER` | `gurii-gabreh` |
   | `REPO_NAME` | `claude-voice-bridge` |

4. 「デプロイ」→「新しいデプロイ」→ 種類の選択で「ウェブアプリ」を選ぶ。
   - 実行するユーザー: 自分
   - アクセスできるユーザー: 全員
5. デプロイすると発行される**ウェブアプリのURL**をコピーし、Claudeに伝えてください。`sidepanel.js`内の`GAS_URL`定数に設定します。
6. コードを更新した場合は、「デプロイを管理」から既存デプロイを編集し、新しいバージョンを選んで再デプロイしてください(URLは変わりません)。

## 動作確認

- トラッカー同期: サイドパネルで「☁️ GitHubへ同期」ボタンを押し、数秒待ってから`data/tracker.json`(GitHub上)に現在のトラッカー内容が反映されているか確認してください。
- ナレッジ化: 「🔍 ルームタスク一覧を抽出」ボタンを押し、数秒待ってから`data/knowledge-log.json`のentries配列に新しい1件が追加されているか確認してください。

反映されない場合は、GASプロジェクトの「実行数」(左メニュー)でエラーログを確認してください。
