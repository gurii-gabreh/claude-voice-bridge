# Claude Voice Bridge

claude.ai(ブラウザ版)との会話を、音声で行うためのChrome拡張機能です。サイドパネルのマイクボタンを押して話すと、内容が自動でclaude.aiの入力欄へ入力・送信され、応答が読み上げられます。

## できること・できないこと

- 音声認識(Web Speech API)・読み上げ(SpeechSynthesis)はブラウザ標準機能のみを使用。追加のAPI契約・料金は発生しません
- 公式のclaude.aiページをそのまま操作するだけで、Claude Code等の別ツール(harness)には該当しないため、Anthropicの利用規約上も問題ありません
- 音声認識(入力側)は、Chromeの仕様上、音声データがGoogleのサーバーへ送信されます(無料ですが完全にローカル完結ではありません)。読み上げ(出力側)は端末内で完結します
- claude.ai側のHTML構造は非公開・可変のため、入力欄・送信ボタン・応答テキストの自動検出がうまくいかない場合があります。その場合はサイドパネル下部の「手動セレクタ設定」で調整してください(手順は下記)

## インストール方法(未パッケージ状態での読み込み)

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このリポジトリのフォルダを選択する
4. ツールバーの拡張機能アイコンから本拡張機能をクリックすると、サイドパネルが開く

## 使い方

1. claude.aiのタブを開き、アクティブにする
2. サイドパネルのマイクボタン🎤をクリック(音声会話モード開始)
3. 話しかけると、自動で文字起こし→claude.aiの入力欄へ送信される
4. 応答が返ってきたら自動で読み上げられ、読み上げが終わると再びマイクが開いて次の発話を待つ
5. 停止する場合はマイクボタン(⏹)を再度クリック

## うまく動かないとき(手動セレクタ設定)

自動検出は「画面下部の入力欄らしき要素」「aria-labelにSend/送信を含むボタン」等のheuristic(推測)で動いています。claude.ai側の実装変更等で検出に失敗する場合、以下の手順で手動指定できます。

1. claude.aiのページでF12(開発者ツール)を開き、Elementsタブで入力欄・送信ボタン・応答メッセージのHTML要素を確認する
2. その要素を一意に絞り込めるCSSセレクタを調べる(要素を右クリック→「Copy」→「Copy selector」等)
3. サイドパネル下部の「手動セレクタ設定」に、それぞれ入力する(入力すると自動的に反映される)

## 既知の制約

- claude.aiの画面構成が変わると、自動検出・手動セレクタの両方が効かなくなる可能性があります
- 音声認識中に読み上げ音声をマイクが拾わないよう、読み上げ中はマイクを開かない設計にしていますが、スピーカーの音量やマイクの感度によっては誤検出する場合があります。イヤホン・ヘッドセットの使用を推奨します
- 応答の完了判定は「1.2秒間、画面に変化が無ければ完了とみなす」という簡易的な仕組みです。長い応答の途中で誤って完了と判定される場合があります
